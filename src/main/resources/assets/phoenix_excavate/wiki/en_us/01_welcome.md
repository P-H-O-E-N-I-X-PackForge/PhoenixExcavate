# Phoenix Excavate: Vein Mining

Excavate breaks a whole vein of matching blocks in one go. It is also server-authoritative and
config-friendly.

## Using it

- Hold a tool and mine a matched block to break the connected vein.
- Toggle **Hold to activate** in settings if you'd rather hold a key than have it always on.
- **Match mode** controls how "connected" is judged (same block, tag, shape, etc.) — click to cycle.

## Match lists

The **Ore list** and **Any list** control which blocks vein-mine. Add a block ID or `#tag` and it
applies next break.

## Server policy

Server owners can lock hunger cost, durability, enchantment respect, max vein size, and
collect-to-inventory behavior. Locked settings show a 🔒 and can't be changed client-side.

## Theme

Excavate shares its color theme with every other Phoenix mod installed. Use **Edit colors...**
to customize it, and it applies everywhere at once.
